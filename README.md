# Calculator Project

## Overview
This project is a simple calculator web application. The calculator allows users to perform basic arithmetic operations such as addition, subtraction, multiplication, and division.

## Files Included

### 1. `index.html`
This file contains the HTML structure of the calculator application. It includes:
- A main container for the calculator.
- An input field to display the results.
- Buttons for digits (0-9), operations (+, -, *, /), a clear button, and an equal button to compute the result.

### 2. `styles.css`
This file provides the styling for the calculator application. It includes:
- Styling for the calculator container.
- Styling for the input field and buttons.
- Background color for the body of the page.

### 3. `script.js`
This file contains the JavaScript functions to handle the calculator's functionality. It includes:
- `btnclick(val)`: Appends the value of the button clicked to the input field.
- `cleardisplay()`: Clears the input field.
- `result()`: Evaluates the expression in the input field and displays the result.

## How to Run the Project
1. Clone the repository or download the project files.
2. Open `index.html` in any web browser.
3. Use the calculator by clicking on the buttons to perform operations.
